# Publication provenance

This repository is a publication/import of the completed SAC-QUTAB study, not a claim that its experiments were conducted during the publication PR sequence.
Original local research HEAD: `2db2331f27d9701ad923bb1c29792ddd64659c1b`.
The original local checkout and Git history are preserved in a separate backup.

The historical reporting index reused the last run's representation hash in five entries. The publication code now hashes each run's own representation path. Original experiment outputs are not rewritten; the historical anomaly remains in the report audit.

The five-member publication assignment uses three PRs, six substantive commits and three primary reviews per member. Bootstrap and merge commits are counted separately. Necessary correction commits are reported, not hidden or padded.

PR creation and reviews may be submitted by an account-switching local automation. Reviews report machine checks of an exact SHA. These records do not establish independent human scientific review or historical individual research effort. The contribution report separates proposed publication responsibilities from observed GitHub activity.
