# Final release checklist

- [ ] Five authenticated accounts with verified commit emails and accepted collaboration access.
- [ ] Exactly fifteen planned PRs merged; actual GitHub audit attached.
- [ ] All five members agree to the contribution report; record agreement in `contribution_signoff.json`.
- [ ] CPU tests and final package checks pass at the exact release SHA.
- [ ] Anonymous fresh checkout replays headline numbers from the release evidence.
- [ ] Report PDF hash matches current visual QA; slides and contribution PDF are present.
- [ ] Repository link targets `GeminusF/sac-qutab/tree/v1.0-final`.
- [ ] Headline release asset hashes match the committed evidence manifest.
- [ ] Full evidence remains local until redistribution permissions are settled.

The local controller creates `v1.0-final` only after its release gates pass. A proposed assignment is not an all-member agreement. Do not edit a sign-off flag to manufacture approval.
